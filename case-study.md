## 3. PROCORE SOLUTION

### 3.1 Project Setup & Planning

**Objective:** Establish centralized project structure

**Procore Implementation:**
1. Create Company Profile + Project
2. Add team members (Superintendent, Foreman, Field Staff)
3. Set project phases:
   - Phase 1: Mobilization
   - Phase 2: Steel Erection
   - Phase 3: Connections & QA
   - Phase 4: Inspection & Closeout

**Benefits:**
- Single source of truth
- Role-based access control
- Clear accountability

---

### 3.2 Budget Management

**Initial Budget:** AUD $500,000 (steel framing portion)

**Procore Features:**
- Cost codes for materials (steel, bolts, paint, etc)
- Labor tracking by task/phase
- Real-time budget vs actual comparison
- Cost forecasting to identify overruns early

**Example Workflow:**

Day 1: Set budget codes Steel Material: $250,000 Labor: $180,000 Equipment: $50,000 Contingency: $20,000

Week 2: Track actual costs Material received: $48,500 (vs budgeted $50,000) Labor: $22,300 (vs budgeted $25,000) → System alerts if trending to overspend

End of Month: Forecasting "At current burn rate, project will exceed budget by $12,000" → Take corrective action BEFORE it's too late


**Impact:**
- Reduced cost overruns by ~10-15% (typical)
- Faster invoicing & payment reconciliation

---

### 3.3 RFI & Submittal Workflow

**Scenario:** Steel supplier provides different bolt specification than approved

**Without Procore:**
1. Email to supervisor (lost in inbox)
2. Supervisor calls engineer
3. Engineer checks plans (manual)
4. Sends back email
5. Confusion about who approved what

**With Procore:**

STEP 1: Create RFI → Supplier uploads attachment with new bolt spec → System automatically notifies stakeholders → Clear description & due date

STEP 2: Review & Approval → Engineer reviews in Procore (auditable) → Comments in-platform (no email threads) → Approves or requests revision

STEP 3: Implementation → RFI marked as Closed → Historical record maintained → Field team sees approved version

RESULT: ✓ No lost emails ✓ Clear approval trail ✓ Field team has correct info ✓ Compliance documented


**Impact:**
- RFI resolution time: 5 days → 1-2 days
- Reduced rework
- Better compliance documentation

## 4. WORKFLOW EXAMPLE - A Typical Day with Procore

**8:00 AM - Site Mobilization**
1. Superintendent logs into Procore on tablet
2. Reviews daily report template
3. Checks weather, crew, equipment status
4. Logs: "Steel delivery delayed, revised schedule posted"

**9:30 AM - Field Work**
1. Foreman notices bolt spec mismatch
2. Takes photo in Procore app
3. Creates RFI: "Bolt specification clarification"
4. System auto-notifies supplier + engineer

**12:00 PM - Lunch Review**
1. PM checks Procore dashboard on phone
2. Sees RFI notification
3. Reviews bolt spec email attachment
4. Approves variant in 2 hours

**3:30 PM - Afternoon Update**
1. Foreman sees approval notification
2. Implements approved spec immediately
3. No rework, no confusion

**5:00 PM - Close of Day**
1. Superintendent uploads progress photos
2. Logs: "8 columns erected, 2 more scheduled tomorrow"

**Result:** Full day documented, no lost communication, proactive issue management
