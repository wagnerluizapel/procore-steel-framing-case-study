# Procore Workflows - Step-by-Step

## Workflow 1: RFI Process

### Scenario: Material Specification Change

**Step 1: Create RFI**
- User: Field Supervisor
- Action: Opens Procore → Documents → RFIs → New
- Input: Title, Description, Attachments
- Assign to: Engineer/Designer
- Due date: 3 days

**Step 2: Notify**
- System automatically emails assigned person
- Creates notification in-app
- No risk of lost emails

**Step 3: Review**
- Engineer logs in
- Reviews attachment (new bolt spec)
- Adds comment: "Approved - matches design intent"
- Changes status: "Answered"

**Step 4: Close**
- Superintendent reviews approval
- Marks RFI as "Closed"
- Field team implements approved spec
- Historical record maintained

**Time saved:** ~4 days vs manual email chain

## Workflow 2: Daily Reporting

### Time: 5:00 PM - End of Day

1. Superintendent opens Procore Daily Report template
2. Fill in:
   - Weather
   - Crew on site
   - Equipment used
   - Tasks completed
   - Safety incidents (if any)
   - Plan for next day
   - Photos/attachments

3. Submit
4. Report auto-distributed to PM, Client, Safety Officer
5. Everyone has same information

**Time saved:** 2 hours manual reporting → 20 mins

## Workflow 3: Budget Tracking

### Scenario: Weekly Cost Review

1. PM opens Procore → Financials → Budget
2. Views by cost code:
   - Steel: $48,500 spent (vs $50,000 budgeted) → 97% ✓
   - Labor: $22,300 spent (vs $25,000 budgeted) → 89% ✓
   - Equipment: $8,200 spent (vs $10,000 budgeted) → 82% ✓

3. Forecasting shows:
   - Project trending $12,000 OVER budget
   - System alerts: "Take corrective action"

4. PM takes action:
   - Optimize labor schedule
   - Review equipment rental
   - Negotiate material pricing

5. By next week, back on track

**Impact:** Proactive cost management instead of reactive surprises
